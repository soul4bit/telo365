# Заключение по визуальной проверке техники Air Squat

**Проект:** TELO365
**Упражнение:** Приседания с собственным весом (Air Squat)
**Дата визуального анализа:** 24.09.2026
**Основание:** видеодемонстрации мужского и женского персонажей, контрольные кадры основных фаз упражнения и результаты технической диагностики 3D-анимаций.

## Мужской персонаж — CH08_NONPBR

**Анимация:** оригинальный Mixamo Air Squat.

| Критерий | Результат визуальной оценки |
| --- | --- |
| Стартовая стойка и постановка стоп | Исходная стойка отображается естественно, стопы расставлены. Равномерность распределения веса визуально не определяется. |
| Контакт пяток с полом | Значительного отрыва пяток не выявлено. Технические измерения показывают небольшие изменения положения геометрии обуви. |
| Направление коленей | Выраженного сведения коленей внутрь не выявлено. Движение визуально согласовано с направлением стоп. |
| Движение таза | Таз перемещается назад и вниз, затем возвращается в исходное положение. Резких скачков положения не обнаружено. |
| Положение позвоночника | Корпус сохраняет контролируемый наклон. Точное положение поясничного отдела не может быть подтверждено из-за одежды персонажа. |
| Глубина приседания | Демонстрируется глубокое приседание, достаточное для наглядного показа движения. |
| Положение рук | Руки перемещаются вперёд и не закрывают основные ориентиры нижней части тела на боковом ракурсе. |
| Визуальные дефекты | Грубых деформаций ног, таза и корпуса, способных существенно исказить представление об упражнении, не обнаружено. |

Анимация демонстрирует последовательное выполнение Air Squat: исходная стойка, контролируемое опускание таза, нижняя точка и возврат в стойку. Существенных дефектов, требующих пересоздания движения или замены персонажа, не выявлено. Для подтверждения пригодности в качестве обучающего эталона нужна проверка специалистом положения позвоночника, таза и нижних конечностей во всём цикле.

| Критерий | Результат визуальной оценки |
| --- | --- |

| Контакт пяток с полом | Значительного отрыва пяток не выявлено. Измерения показывают небольшие изменения положения контрольных точек обуви. |
| Направление коленей | Выраженного сведения коленей внутрь не обнаружено. |
| Движение таза | Таз перемещается назад и вниз. Опускание и возврат происходят последовательно, без обнаруженных резких скачков положения. |
| Положение позвоночника | Наклон корпуса выглядит контролируемым. Точное положение поясничного отдела требует оценки специалистом. |
| Глубина приседания | Персонаж демонстрирует глубокое приседание с выраженным сгибанием коленных и тазобедренных суставов. |
| Положение рук | Руки согнуты и располагаются перед туловищем, не препятствуя наблюдению за нижней частью тела с бокового ракурса. |
| Визуальные дефекты | Грубых деформаций ног и таза, наблюдавшихся в ранних тестовых анимациях, не выявлено. |

Анимация Jody демонстрирует полный последовательный цикл Air Squat. Существенных технических дефектов, требующих полной переработки анимации, не выявлено. Подтверждение обучающей пригодности остаётся за квалифицированным специалистом по технике.

## Общий результат

Обе анимации демонстрируют узнаваемое движение Air Squat. Не выявлены прежние грубые деформации персонажей, значительное скольжение обуви или существенные скачки положения тела при повторении анимации. Небольшие пересечения геометрии обуви с условной плоскостью пола относятся к отображению 3D-сцены и сами по себе не подтверждают нарушение техники.
