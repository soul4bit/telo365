# Обновление без ввода sudo-пароля

После однократной установки релиза через `install-app.sh` на ВМ появляется
команда `sudo telo365-deploy`, доступная только пользователю `max` без пароля.

Она принимает только `/home/max/telo365-upload.tar.gz`, проверяет его состав,
извлекает лишь `dist`, `server` и Nodemailer, создаёт резервную копию SQLite,
перезапускает фиксированную службу `telo365` и откатывает код при неуспешной
проверке здоровья. Конфигурации systemd, nginx, sudo и почты из загрузки не
извлекаются. Поэтому обновляемое приложение по-прежнему работает от системного
пользователя `telo365`, а не с правами root.

Подготовка архива на рабочем компьютере:

```powershell
tar.exe -czf telo365-upload.tar.gz dist server node_modules/nodemailer
scp telo365-upload.tar.gz telo365:/home/max/
ssh telo365 "sudo telo365-deploy"
```

Команду `install-app.sh` всё ещё нужно запускать с обычным sudo-паролем, если
нужно изменить системную конфигурацию или впервые установить этот механизм.
