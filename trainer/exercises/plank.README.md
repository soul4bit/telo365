# plank: рабочая заготовка

Эта папка создана командой `trainer:new`. Она **не содержит** фиктивной GLB-анимации и не меняет production viewer.

1. Открой канонический рабочий Blender-файл из `trainer/characters.manifest.json`.
2. Создай или ретаргетируй отдельную анимацию для мужчины и женщины. Не меняй канонический риг.
3. Проверь позы, технику и деформации вручную.
4. Экспортируй клипы в пути, записанные в `exercises/plank.json`.
5. Обнови duration, cameraPreset, equipment и статусы только по итогам проверки.
6. Выполни `npm run trainer:verify -- --exercise plank`.

Шаблоны Blender намеренно останавливаются до создания настоящего движения.
